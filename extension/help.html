学习通全自动助手 · 使用说明

这是一个浏览器扩展（Manifest V3），在超星学习通 / 泛雅页面上全自动完成：视频播放、视频弹题作答、章节跳转、学习检测 AI 答题。

1. 安装

  1. 浏览器地址栏打开 edge://extensions（Chrome 为 chrome://extensions）。
  2. 打开右上角「开发人员模式」。
  3. 点「加载解压缩的扩展」，选择本扩展目录（含 manifest.json 的那一层）。
  4. 首次安装后点扩展图标 →「高级设置」→「AI 接口」填接口与 Key（弹窗里不再放 AI 配置，全在设置页），然后点页面顶部的「测试 AI 连接」确认可用。

接口需兼容 OpenAI 的 /chat/completions。如果服务不支持 response_format，把「使用 JSON 模式」关掉。

「模型名」是下拉框：内置了各家的常用模型；点右边「拉取」会按你填的 Base URL 请求一次 /models，把该 Key 能用的模型全列出来（部分中转/自建服务不提供这个接口，会提示失败，此时选「自定义…」手填即可）。

3. 工作流程

  • 视频页：检测到未完成任务点自动开播（音量 0，内核后台不暂停）；页面隐藏/被遮挡/被站点暂停都会自动续播。
  • 视频弹题：识别单选 / 多选 / 判断（按 input type 与题目标记双重判断），先问 AI；AI 答错换答案重问，AI 不可用时按选项组合暴力枚举。答对后自动点「继续学习」并恢复播放。
  • 学完跳转：视频播放结束或任务点标记完成 → 等设定延迟 → 自动点「下一节」；连续跳转有防重复点击仲裁，避免一次跳两节。
  • 学习检测 / 章节测验：抓取所有题目 → 批量问 AI → 按题型填答 → 提交并确认弹窗。通过判定只看任务条上的「学习测验」任务点有没有变成「已完成」（站点不给分数，也不看及格线）：任务点完成就直接下一节；仍是「未完成」就把错题连同上次的错误选项重新交给 AI，再提交，循环到任务点完成或达到最大轮数。
  • 手动踢一次：扩展图标里的「AI 学习检测」是按钮（不是开关）—— 停在题目页点它，就对当前页立刻跑一轮，不用等自动轮询。总开关在高级设置「学习检测 → 启用 AI 答题」。
  • 答案缓存：同一个题干答对后会缓存，下次遇到直接命中，省 token。

4. 页面浮窗

学习页面右下角有状态卡：实时显示当前阶段（播放 / 弹题 / 测验 / 跳转）与最近日志，可暂停、改配置、清日志，拖动标题栏可换位置。

5. 切到别的窗口也要继续跑（关掉浏览器睡眠标签页）

插件自己已经用「音量 0」保活、伪造页面可见状态，正常情况下切到别的窗口视频也不会暂停。但浏览器还有一层策略：标签页长时间不可见时会被降频 / 冻结（定时器从 1 秒一次降到 1 分钟一次，久了整页冻结），表现为「切走一会儿回来发现卡在原地、章节不往下走」。

这一层插件无法替你改（浏览器不提供修改「睡眠标签页 / 效率模式」白名单的接口），需要手动设一次：

  1. Edge 地址栏打开 edge://settings/system；
  2. 关掉「使用睡眠标签页节省资源」（新版叫「睡眠标签页」）；
  3. 如果开着「效率模式」，点进去把 chaoxing.com 加入「从不对这些站点启用」列表。

设完再刷新学习页即可。Chrome 同理：chrome://settings/performance。

6. 设置页怎么用

设置页顶部有搜索框，直接搜「倍速」「超时」「轮数」就能定位到那一项；下面是「常用」6 个开关，日常只用这几个。其余按主题收在可折叠的卡片里，收起时标题右边会显示当前取值（如「续播 开 · 音量0 开 · 倍速 1×」），点标题才展开。所有改动即时保存，不用点保存按钮。

「自动学习」是只管播放 / 弹题 / 答题 / 跳章的总开关；「防暂停」和「字体采集」不在它管辖范围内，各有自己的开关——这就是以前「总开关」让人迷惑的地方，现在文案与分组都分开了。

7. 调试模式

设置页最下面「调试」→「调试模式」，默认关闭。关着时下面的日志级别、字体样本采集器、改代码自动重载、本地命令桥不会生成，页面上翻不到；打开后才出现。这些都属于「日常用不上、排查或开发时才需要」的项。

本地命令桥是给 tools/_cmd-bridge.mjs 用的：开关打开后，后台会按你填的「命令桥地址」每 1.2 秒取一次命令。地址默认留空＝完全不轮询，不会带任何写死的地址；要本机调试自己填 http://127.0.0.1:8765。

8. 常见问题

  • 提示「未找到提交按钮」：说明页面结构与内置选择器不一致。把日志级别调成 debug，在扩展设置页复制日志反馈即可定位。
  • AI 返回为空 / 格式错误：多为接口不支持 JSON 模式或模型太弱。关掉 JSON 模式，或换更强的模型。
  • 视频不自动播放：浏览器要求「有用户手势」时才允许有声播放。扩展会用 volume=0 的方式规避；若浏览器策略仍拦截，在页面上点一下任意位置即可。
  • 章节被锁（需完成之前闯关任务点）：扩展会等待解锁并按配置刷新重试。
该扩展只在本机浏览器内运行：题目内容仅发送到你自己填写的 AI 接口。请遵守所在学校与平台的课程学习规定，成绩类考核请以平台最终结果为准。
